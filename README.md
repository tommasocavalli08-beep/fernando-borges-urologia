# Dr. Fernando Borges Ribeiro — Urologia

Site institucional premium desenvolvido em Next.js para o Dr. Fernando Borges Ribeiro, médico urologista e cirurgião robótico.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm start
```

Inclui páginas individuais de tratamentos, SEO técnico, dados estruturados médicos e locais, sitemap e integração com WhatsApp.
